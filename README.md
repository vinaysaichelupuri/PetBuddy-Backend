# PetBuddy: Your Pet's Best Friend
### PetBuddy is a mobile application designed to simplify pet care. It helps you keep track of your pet's health, schedule reminders, and maintain a detailed activity log.
## Key Features:
 * Personalized Pet Profiles: Create detailed profiles for each pet, including health records and photos.
 * Smart Reminders: Set reminders for medications, vaccinations, and appointments.
 * Activity Tracking: Log daily activities like walks, playtime, and feeding.
 * Pet Service Finder: Discover nearby pet services, including grooming, training, and boarding.
 * Training Tips: Access valuable training resources and tips.
## Getting Started:
### Prerequisites:
 * Node.js and npm (or yarn)
### Installation:
 * Clone the repository:
 ```
   git clone https://github.com/vinaysaichelupuri/PetBuddy-Backend
```
 * Navigate to the directory:
 ```
   cd PetBuddy-Backend
```

 * Install dependencies:
 ```
   npm install
```

 * Run the application:
 ```
   npm start
```

Testing:
```
npm test
```

### Technology Stack:
 * Backend: Node.js, Express.js
 * Database: MongoDB
